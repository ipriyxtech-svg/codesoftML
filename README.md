# 📖 About

This repository contains my **Machine Learning Internship Projects** completed during the **CodeSoft ML Internship**.

The projects focus on solving real-world classification problems using Python, data preprocessing, feature engineering, model training, and evaluation.

---

# 📂 Projects Included

## 🎬 Movie Genre Classification

Predict movie genres from text descriptions using Natural Language Processing (NLP) and Machine Learning.

**Key Features**

- Text Preprocessing
- TF-IDF Vectorization
- Genre Prediction
- Classification Models
- Accuracy Evaluation

---

## 💳 Credit Card Fraud Detection

Detect fraudulent credit card transactions using supervised Machine Learning algorithms.

**Key Features**

- Fraud Detection
- Data Balancing
- Feature Engineering
- Model Evaluation
- Precision & Recall Analysis

---

## 📞 Customer Churn Prediction

Predict whether a customer is likely to leave a service using customer behavior and historical data.

**Key Features**

- Churn Prediction
- Data Cleaning
- Feature Selection
- Classification Models
- Performance Metrics
